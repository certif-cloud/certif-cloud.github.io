# CERTIF-CLOUD

Proyecto de innovación educativa del **IES Miguel Herrero Pereda** (Torrelavega, Cantabria) para el curso 2026/27.

Ruta intermodular de 2.º de ASIR que conecta los módulos del ciclo con las certificaciones cloud de AWS y Microsoft Azure.

En esta web iremos publicando, por Escalas, los recursos educativos abiertos del proyecto: laboratorios guiados, videotutoriales, bancos de preguntas y plantillas de Infraestructura como Código.
