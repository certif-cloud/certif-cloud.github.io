# Guía docente

Esta guía está pensada para el profesorado de otros centros que quiera implantar la metodología CERTIF-CLOUD en su ciclo de ASIR.

Incluirá, entre otros contenidos:

- Cómo organizar la coordinación entre módulos.
- Cómo preparar las cuentas cloud del alumnado y controlar el gasto.
- Calendario tipo de un curso completo.
- Rúbricas y criterios para el Proyecto Intermodular.

!!! info "En preparación"
    La guía se irá ampliando a medida que avance el proyecto.
