# Recursos educativos abiertos

El proyecto publicará **30 recursos educativos abiertos**, organizados por Escalas:

- **Laboratorios guiados**: prácticas paso a paso en AWS y Azure.
- **Videotutoriales**: explicaciones y demostraciones en vídeo.
- **Bancos de preguntas**: preguntas de práctica de elaboración propia, con estilo de certificación.
- **Plantillas de Infraestructura como Código**: código Terraform reutilizable, con destrucción automática de recursos para controlar el gasto.

!!! info "Recursos publicados: 0 de 30"
    El catálogo se irá completando a lo largo del curso.
